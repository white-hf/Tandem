## 1. Executive Summary & Engineering Motivation

While engineering mission-critical logistics and supply-chain systems (handling operations, warehouse tracking, and courier dispatch) where **over 90% of the code was generated by autonomous AI Coding Agents**, software delivery hit a critical bottleneck: **raw code generation speed outpaced engineering governance**.

Traditional "vibing code" (chat-driven coding) suffered from three failure modes in production:
1. **Fragmented Chat-Driven Chaos:** Business requirements from non-technical stakeholders (operations managers, warehouse leads, drivers) scattered across chat apps led to spec decay, unorganized ad-hoc patches, and zero sprint planning.
2. **The "Black-Box" Agent Problem:** Agents coded, refactored, and executed tests in silos. Engineering leads lacked visibility into what was actually built, whether tests passed, or if the code adhered to architecture standards until regressions broke production.
3. **Lack of Industrial-Grade Rigor:** Casual conversational prompts lacked core agile invariants—immutable PRD baselines, structured sprint cycles, reproducible verification, and auditability.

To solve this, I designed and open-sourced **Tandem**—a lightweight agile delivery memory and coordination platform built for **1–10 person hybrid teams (Human Engineers + AI Agents)** to transform conversational code generation into structured, white-box, industrial-grade agile software engineering.

## 2. Core Architecture & Feature Matrix

### A. Multi-Stakeholder Quick Intake & Spec Baselining
- **Problem Solved:** Ad-hoc chat requests causing requirements drift and lost context.
- **Implementation:** Developed a Quick Capture web interface that transforms natural-language stakeholder inputs into structured Issues with explicit acceptance criteria. Bound PRD and System Design revisions to **SHA-256 cryptographic digests**, requiring agents to verify current baselines via Model Context Protocol (MCP) before coding.

### B. Lightweight Agile Sprint & Lifecycle Orchestration
- **Problem Solved:** Unplanned, chaotic AI code generation lacking sprint cadence and scope boundaries.
- **Implementation:** Built a high-density, 5-column Kanban board (`Backlog` ➔ `Ready` ➔ `In Progress` ➔ `In Review` ➔ `Done`) and Scrum Cycle planner in React 19 / Fastify. Supports dynamic sprint assignments, Definition of Done (DoD) tracking, and clear state machines, turning conversational coding into structured agile iterations.

### C. White-Box Agent Execution & Reproducible Evidence Chain
- **Problem Solved:** Black-box agent development and unverified testing assumptions.
- **Implementation:** Designed a machine-verifiable delivery protocol via custom **MCP Streamable HTTP** endpoints. Agents log semantic checkpoints (`record_checkpoint`), attach verifiable test/build artifacts (`attach_evidence`), and submit structured handoffs (`submit_handoff`), making agent implementation and verification 100% transparent and auditable.

### D. Human-in-the-Loop Attention & Decision Inbox
- **Problem Solved:** Notification fatigue and manual code review exhaustion.
- **Implementation:** Engineered a dedicated **Attention Inbox** that filters non-critical agent noise and elevates only high-risk architectural decisions (e.g., spec revisions, sprint activations, final delivery handoffs) for human sign-off.

### E. Zero-Ops Production-Ready Architecture
- **Problem Solved:** Complex infrastructure overhead for lean teams.
- **Implementation:** Containerized the entire platform into a secure, single-box Docker Compose stack (Fastify API, Nginx SPA, isolated PostgreSQL 17) featuring read-only root filesystems, automated database migrations, and one-click shell lifecycle management.

## 3. Technology Stack & Key Protocols

- **Agent Protocol:** Model Context Protocol (MCP v1.x, Streamable HTTP)
- **Backend & Domain Engine:** Node.js 22 LTS, Fastify, TypeScript (Strict Mode), Zod, Domain-Driven Design (DDD)
- **Frontend & UI:** React 19, Vite, TanStack Query, Custom High-Density CSS
- **Persistence & Audit:** PostgreSQL 17, Hybrid Storage Model (JSONB State Tree + Relational Projections), Append-Only Activity Log
- **Infrastructure & Deployment:** Docker Compose, Nginx, Multi-Stage Builds, Shell Scripting
- **Testing & Verification:** Vitest, Testcontainers, E2E Integration Suites
