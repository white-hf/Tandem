## Field: Description (Paste directly into LinkedIn — 1,760 Characters)

Architected and open-sourced Tandem, a lightweight agile coordination platform built for 1–10 person hybrid teams (Human Engineers + autonomous AI Coding Agents). Created to eliminate context drift, opaque development, and lack of engineering discipline when >90% of code is generated by AI agents.

Problem & Motivation:
While building complex logistics systems across operations, warehouses, and driver dispatch, chat-driven "vibing code" broke down: fragmented requests across chat apps caused spec decay, agent coding/testing remained a black box, and casual prompts lacked industrial-grade agile rigor (baselines, sprints, reproducible verification).

Key Technical Highlights:
• Agile Sprint Orchestration: Built a high-density 5-column Kanban board and Scrum Cycle planner in React 19/Fastify, turning ad-hoc AI coding into structured sprints with explicit DoD tracking.
• White-Box Agent Execution via MCP: Implemented custom Model Context Protocol (MCP) Streamable HTTP endpoints. Agents log semantic checkpoints, attach reproducible test/build evidence (e.g., test logs, APK hashes), and submit structured handoffs, making agent execution 100% transparent.
• Stakeholder Intake & Spec Baselining: Designed a Quick Capture web UI converting non-technical requests into structured Issues. Anchored PRD/Design revisions with SHA-256 digests, forcing agents to verify baselines before coding.
• Human Attention Inbox: Engineered an oversight inbox that filters agent noise and elevates only critical architectural decisions (spec changes, sprint activations) for human approval.
• Zero-Ops Docker Stack: Containerized the platform into a secure single-box Docker Compose stack (Node.js 22, Fastify, Nginx, PostgreSQL 17) with automated migrations and zero external dependencies.

Tech Stack: TypeScript, Node.js 22, MCP, React 19, Fastify, PostgreSQL 17, Docker Compose, Vitest.
